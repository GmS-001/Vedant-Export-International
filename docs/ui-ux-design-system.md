# UI/UX Design System

## 1. Design Philosophy

The website should feel:

* Minimal
* Premium
* Modern
* International
* Trustworthy
* Calm
* Professional
* Product-focused

The visual language should take inspiration from Apple's principles of simplicity, typography, spacing, hierarchy and restrained visual design.

The website should **not** look like:

* A generic agricultural website
* A traditional trading-company website
* A WordPress template
* An AI-generated landing page
* An overly colorful website
* A dashboard
* A visually overloaded website

### Core Principle

> **Less decoration. More clarity.**

Every visual element should have a purpose.

---

# 2. Typography

Use **Inter** as the primary typeface.

Inter should be used consistently across the entire website.

### Font hierarchy

| Element        |    Size | Weight |
| -------------- | ------: | -----: |
| Display / Hero | 56–72px |    600 |
| H1             | 48–56px |    600 |
| H2             | 36–44px |    600 |
| H3             | 24–28px |    600 |
| H4             | 20–22px |    600 |
| Body Large     |    18px |    400 |
| Body           |    16px |    400 |
| Small          |    14px |    400 |
| Caption        | 12–13px |    400 |

Mobile typography should scale down appropriately.

### Typography rules

* Use strong typography rather than decorative graphics.
* Avoid excessive bold text.
* Avoid all-caps except for small labels.
* Keep paragraphs comfortable to read.
* Use generous line-height.
* Headings should be short and visually strong.

---

# 3. Color System

Use a restrained neutral palette with a subtle agricultural green accent.

### Primary Colors

```text
Background:        #FFFFFF
Primary Text:      #111111
Secondary Text:    #666666
Muted Text:        #888888
Border:            #E5E5E5
Light Background:  #F7F7F5
```

### Brand Accent

```text
Primary Green:     #315C45
Dark Green:        #234534
Light Green:       #EAF1EC
```

Green should be used primarily for:

* Primary CTA buttons
* Important links
* Small accents
* Selected states
* Trust indicators
* Important UI elements

Do not make the entire website green.

### Color principle

Approximately:

```text
80–90% Neutral
10–20% Brand Accent
```

Avoid:

* Bright gradients
* Excessive green
* Neon colors
* Multiple competing accent colors
* Decorative color blocks without purpose

---

```text

```

### Section spacing

Desktop:

```text
Small section:     64px
Normal section:    80px
Large section:     120px
Hero section:      120–160px
```

Mobile:

```text
Small section:     40px
Normal section:    56px
Large section:     72px
Hero section:      72–96px
```

The website should feel spacious.

Avoid tightly packed sections.

---

# 5. Layout

Use a centered content container.

```text
Maximum content width: 1200–1280px
```

Use generous horizontal padding:

```text
Desktop: 32–48px
Tablet: 24–32px
Mobile: 16–20px
```

Content should generally use a clear grid rather than arbitrary positioning.

---

# 6. Buttons

Buttons should be simple and confident.

### Primary Button

```text
Background: Primary Green
Text: White
Border Radius: 8px
Height: 44–48px
Horizontal Padding: 20–24px
Font Weight: 500
```

Primary CTA examples:

* Request a Quote
* Contact Us
* Start an Inquiry

### Secondary Button

```text
Background: Transparent
Text: Primary Text
Border: 1px solid #D5D5D5
Border Radius: 8px
```

### Button rules

* Avoid excessive rounded/pill buttons.
* Avoid gradients.
* Avoid oversized buttons.
* Use one primary CTA per major section where possible.
* Buttons should have clear hover and focus states.
* Buttons must remain easy to tap on mobile.

---

# 7. Cards

Cards should be minimal.

### Default Card

```text
Background: White
Border: 1px solid #E5E5E5
Border Radius: 12px
Padding: 24px
```

Use cards for:

* Products
* Capabilities
* Markets
* Certifications
* Process steps
* Important information

Avoid turning every section into cards.

### Card behavior

Cards may have subtle hover effects:

```text
Transform: translateY(-2px)
Border: slightly darker
Shadow: subtle
Transition: 200–250ms
```

No dramatic movement.

---

# 8. Navigation

The navigation should be clean and minimal.

### Desktop

Recommended structure:

```text
Logo

Products
About
Sourcing
Quality
Markets
Insights

Request a Quote
```

The Request a Quote button should be visually emphasized.

Navigation should remain uncluttered.

### Mobile

Use:

```text
Logo
Menu icon
```

Open a clean mobile navigation drawer/menu.

The Request a Quote CTA should remain easily accessible.

---

# 9. Header

The header should be:

* Clean
* Lightweight
* Sticky where appropriate
* White or very subtle background
* Minimal border/shadow

Avoid large decorative headers.

The header should not consume excessive vertical space.

---

# 11. Forms

Forms are critical because Request a Quote is the primary conversion.

Forms should feel:

* Simple
* Trustworthy
* Spacious
* Easy to understand
* Mobile-friendly

### Input style

```text
Height: 48–52px
Border: 1px solid #DADADA
Border Radius: 8px
Background: White
Padding: 12–16px
```

Focus state:

```text
Border: Primary Green
Visible focus ring
```

Labels should always be visible.

Do not rely only on placeholders.

### Form layout

Desktop:

```text
Two-column grid where appropriate
```

Mobile:

```text
Single-column layout
```

Required fields should be clearly indicated.

Validation errors should be visible and understandable.

---

# 12. Image Style

Images are an important part of the brand.

Use:

* High-quality real agricultural/product photography
* Natural lighting
* Clean compositions
* Real products
* Real sourcing/packing/export environments
* International business context

Prefer authentic photography over generic stock imagery.

Avoid:

* Artificial AI-generated agricultural scenes
* Excessive filters
* Overly saturated images
* Generic corporate stock photos
* Busy compositions

### Image treatment

Use:

```text
Border Radius: 12–16px
```

Images should feel editorial and premium.

---

# 13. Product Images

Product images should clearly communicate the actual product.

Prefer:

* Clean product photography
* Neutral backgrounds
* Close-up product details
* Packaging where relevant
* Multiple angles when useful

Product images must not misrepresent product quality, grade, packaging or availability.

---

# 14. Animation

Animations must be subtle and purposeful.

Allowed:

* Fade-in
* Small slide/reveal
* Subtle hover effects
* Image transitions
* Navigation transitions
* Very subtle hero interactions
* Number/stat animations when meaningful

### Animation timing

```text
Micro interaction: 150–200ms
Normal transition: 200–300ms
Large transition: 300–500ms
```

### Animation rules

Never use:

* Excessive parallax
* Constant movement
* Bouncing elements
* Large animated backgrounds
* Excessive card movement
* Decorative animations everywhere

Animation should never negatively affect:

* Performance
* Accessibility
* SEO
* Mobile usability

Respect `prefers-reduced-motion`.

---

# 15. Border Radius

Use a restrained radius system.

```text
Inputs:       8px
Buttons:      8px
Cards:        12px
Images:       12–16px
Large panels: 16px
```

Avoid excessive pill-shaped components.

---

# 16. Shadows

Use shadows sparingly.

Default components should primarily use borders rather than shadows.

When required:

```text
Subtle shadow only
Low opacity
Large blur
```

Avoid strong floating-card shadows.

---

# 17. Icons

Use one consistent icon system.

Icons should be:

* Simple
* Minimal
* Line-based
* Consistent in stroke width

Icons should support content rather than become decoration.

Do not use emojis as UI icons.

---

# 18. Responsive Design

The website must be mobile-first.

Required layouts:

```text
Mobile
Tablet
Laptop
Desktop
Large Desktop
```

Important rules:

* No horizontal scrolling
* Buttons remain easily tappable
* Forms become single-column on mobile
* Navigation becomes mobile navigation
* Typography scales appropriately
* Images remain optimized
* Important CTAs remain visible
* Request a Quote workflow must be particularly easy on mobile

---

# 19. Accessibility

The design system must support:

* Semantic HTML
* Keyboard navigation
* Visible focus states
* Sufficient color contrast
* Accessible form labels
* Accessible validation errors
* Alt text for meaningful images
* Reduced-motion preferences
* Touch-friendly controls

Accessibility must not be sacrificed for visual design.

---

# 20. Visual Hierarchy

Every page should have a clear hierarchy:

```text
Page Purpose
     ↓
Hero / Main Message
     ↓
Supporting Information
     ↓
Products / Capabilities / Evidence
     ↓
CTA
```

Users should understand the purpose of a page within seconds.

---

# 21. Design Consistency

All pages must use the same:

* Typography
* Colors
* Spacing
* Buttons
* Cards
* Form controls
* Border radius
* Icon style
* Animation behavior
* Responsive behavior

Do not create page-specific visual styles unless there is a strong reason.

---

# 22. Design Decision Authority

This document is the **single source of truth for the website's visual and UI design system**.

Frontend implementation must follow this document.

Developers and AI coding agents must not independently introduce:

* New colors
* New fonts
* New spacing systems
* New button styles
* New card styles
* New animation patterns
* New visual themes

If a new design decision is required, it must first be added to this document before implementation.

---

# 23. Core Design Rule

> **Make the website feel premium through typography, spacing, hierarchy, photography and restraint — not through decoration.**

The final experience should feel:

**Clean → Premium → Modern → Trustworthy → International → Easy to use**
