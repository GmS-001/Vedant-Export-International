# SEO Strategy

## 1. Purpose

This document defines the SEO strategy for the Vedant Exports International website.

The primary SEO objective is:

> **Make Vedant Exports International discoverable to relevant international B2B buyers searching for Indian agricultural and export products, while converting that organic traffic into qualified business inquiries.**

SEO should support the overall business goals:

```text
Search Visibility
      ↓
Relevant International Buyers
      ↓
Product / Company Pages
      ↓
Trust & Information
      ↓
Request a Quote
      ↓
Qualified B2B Inquiry
```

SEO is not treated as a separate marketing layer.

It must be integrated into:

* Website architecture
* Content
* Product pages
* Technical implementation
* Internal linking
* Images
* Metadata
* Performance
* Structured data
* International targeting

---

# 2. SEO Goals

## Primary Goals

1. Increase organic visibility for relevant export-related searches.
2. Attract international B2B buyers rather than generic consumers.
3. Rank product pages for commercially relevant searches.
4. Build topical authority around products and export capabilities.
5. Build trust through useful company and sourcing information.
6. Generate qualified quote requests.
7. Establish a scalable SEO foundation for future products and markets.

---

Potential target markets include:

* United States

SEO should prioritize buyer intent rather than maximizing raw visitor numbers.

---

# 4. SEO Philosophy

The website should follow:

> **Relevant traffic over maximum traffic.**

A page receiving 1,000 irrelevant visitors is less valuable than a page receiving 20 qualified importers.

SEO should therefore prioritize:

* Product relevance
* Commercial intent
* Export intent
* Country intent
* Trust
* Search usefulness
* Clear inquiry pathways

Avoid keyword stuffing.

Write for buyers first and search engines second.

# 6. SEO Architecture

The website should use clean, descriptive URLs.

Preferred structure:

```text
/
 /about
 /products
 /products/{product-slug}
 /sourcing
 /quality
 /markets
 /insights
 /contact
 /request-a-quote
```

Examples:

```text
/products/moringa-powder
/products/turmeric-powder
```

Avoid:

```text
/product?id=123
/page123
/p123
/product-final-new
```

URLs should be:

* Short
* Descriptive
* Stable
* Lowercase
* Hyphen-separated
* Human-readable

# 9. Product SEO

Product pages are among the most important SEO assets on the website.

Each product should have a dedicated URL.

Example:

```text
/products/moringa-powder
```

A product page should contain useful, buyer-oriented information such as:

* Product name
* Product description
* Origin
* Product specifications
* Available variants
* Packaging options
* Applications
* Minimum order quantity where applicable
* Export availability
* Relevant markets
* Quality information
* Request Quote CTA

The page should answer the questions an importer would realistically have.

# 23. XML Sitemap

The website should generate an XML sitemap.

The sitemap should include important indexable pages such as:

* Homepage
* Product listing
* Product pages
* Important company pages
* Market pages
* Published insights

It should not include:

* API routes
* Internal utility pages
* Duplicate URLs
* Redirect URLs
* Non-indexable pages

The sitemap should be submitted to Google Search Console.

---

# 24. Robots.txt

A valid `robots.txt` file should exist.

Its purpose is to control crawler access to areas that should not be crawled.

The robots configuration must not accidentally block:

* Product pages
* Important content
* CSS/JS required for rendering
* Sitemap discovery

Do not use `robots.txt` as the primary method for removing already-indexed content.

---

# 25. Canonical URLs

Every important indexable page should have a canonical URL.

Canonical URLs should prevent accidental duplication caused by:

* Query parameters
* Alternate URL forms
* Duplicate routes
* Tracking parameters

Example:

```text
https://www.vedantexportsinternational.com/products/moringa-powder
```

should be the canonical version of that product page.

---

* Communicate commercial relevance
* Encourage qualified clicks


---

# 29. Heading Structure

Each page should have one clear primary H1.

Recommended hierarchy:

```text
H1
 ├── H2
 │    ├── H3
 │    └── H3
 └── H2
      └── H3
```

Headings should describe actual content.

Do not use heading tags merely for visual styling.

Typography and visual appearance should be controlled by the design system.

---

# 30. Structured Data

Structured data should be implemented where relevant and supported by actual page content.

Potential schema types include:

### Organization

For the company.

### WebSite

For the main website.

### Product

For product pages where the content qualifies.

### BreadcrumbList

For hierarchical pages.

### Article

For published insights/articles.

Structured data must accurately represent visible page information.

Do not add fake ratings, reviews, prices, or availability.

---

# 31. Breadcrumbs

Breadcrumbs may be used where they improve navigation and hierarchy.

Example:

```text

  /
```

# 32. Image SEO

Images should support both users and search engines.

Use:

* Descriptive filenames
* Descriptive alt text
* Appropriate dimensions
* Modern image formats where appropriate
* Compression
* Responsive images
* Lazy loading where appropriate

Example filename:

```text
moringa-powder-india-export.jpg
```

Avoid:

```text
IMG_9384.jpg
image-final-2.jpg
```

---

# 33. Alt Text

Alt text should describe the actual image.

Good:

```text
Bulk moringa powder prepared for export packaging
```

Poor:

```text
moringa powder exporter India best supplier cheap bulk
```

Alt text should not become keyword stuffing.

Decorative images may use empty alt attributes where appropriate.

---

# 34. Core Web Vitals

Technical SEO must prioritize website performance.

Important areas include:

* Largest Contentful Paint
* Interaction to Next Paint
* Cumulative Layout Shift

The frontend should therefore:

* Optimize images
* Minimize unnecessary JavaScript
* Use appropriate rendering strategies
* Avoid layout shifts
* Optimize fonts
* Lazy-load non-critical content
* Minimize third-party scripts

Performance decisions are defined further in the frontend architecture.

---

# 35. Mobile SEO

The website must be mobile-first.

Mobile users should be able to:

* Browse products
* Read product information
* Contact the company
* Submit a quote request
* Use WhatsApp/contact CTAs

Important content must not be hidden from mobile users.

Avoid intrusive popups and difficult mobile forms.

---

# 36. JavaScript and Rendering

SEO-critical content should be rendered in a way that search engines can reliably discover.

Next.js should use:

* Server Components by default
* Server-side rendering where appropriate
* Static generation where appropriate
* Client Components only where interaction requires them

Do not make the entire website dependent on client-side rendering unnecessarily.

* Business address
* Export capabilities

* Quality processes

---

# 44. Duplicate Content

Avoid duplicate pages created from:

* URL parameters
* Product variants
* Similar market pages
* Repeated descriptions
* Multiple URLs for the same product

Product descriptions should be genuinely useful and sufficiently differentiated.

---

# 45. Thin Content

Do not publish a page simply because a keyword exists.

A page should exist only when it provides meaningful value.

Examples of pages that may be rejected:

```text
/agricultural-products-india
/agricultural-products-india-exporter
/agricultural-products-india-supplier
/agricultural-products-india-wholesaler
```

if they contain essentially the same content.

One strong page is preferable to many thin pages.

---

# 46. SEO Content Governance

Before publishing a new SEO page, verify:

```text
Is there a real business purpose?
        ↓
Is there genuine search intent?
        ↓
Can we provide useful information?
        ↓
Is the content different from existing pages?
        ↓
Does it help the buyer?
        ↓
Does it support a business conversion?
```

If the answer is no, do not create the page merely for SEO.

The ultimate SEO success metric is not simply ranking.

It is:

```text
Relevant Search
      ↓

      ↓
Useful Product Information
      ↓
```
